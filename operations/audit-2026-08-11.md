## CRITICAL — all fixed

### 1. The process never exits cleanly [V]
`app.py:2369`. `socketio.stop()` under eventlet is `raise SystemExit`, which only
works inside the WSGI greenthread; it is raised in a background greenthread, so
`socketio.run()` keeps serving. Observed both outcomes:

```
16:34:14  Main process exited, code=killed, status=9/KILL   result 'timeout'   (45s hang)
16:50:23  Main process exited, code=killed, status=7/BUS    result 'signal'    (crash in teardown)
```

Every restart is either 45s of radio downtime ending in SIGKILL, or a SIGBUS.
Neither runs the final `observations.maybe_save`; USB and the Hailo VDevice are
torn down uncleanly. **Fix:** `os._exit(0)` at the end of `_do_shutdown`.

### 2. Remote XSS from radio traffic → the console [C, attack path verified]
`map.js:149,158,167,177-184`. AIS `shipname`/`destination` are stored with only
`.strip()` (`ais_receiver.py:207-218`) and concatenated into Leaflet
`bindTooltip`/`bindPopup`. Leaflet does `innerHTML = e` for string content, and
AIS 6-bit ASCII includes `<` and `>`. `permanent: true` means it renders with no
user interaction. A 20-char shipname fits `<svg onload=...>`.
**Fix:** escape, or build nodes with `textContent`.
*(The decoder feed panels — ACARS, pager, APRS, ISM, SEI — are all correctly
escaped via `createElement`/`textContent`. The hole is only in `map.js`.)*

### 3. Repetition penalty is inverted [V]
`transcriber.py:277` divides unconditionally. HF's processor is
`score * penalty if score < 0 else score / penalty`; Whisper logits are mostly
negative. Executed: a penalised token went `-8.0 → -5.333`, i.e. **more** likely.
The anti-repetition guard is a 1.5× repetition *reward* across most of the vocab.

### 4. IQSegmenter noise floor is poisoned by its own signal [V]
`iq_segmenter.py:157` updates the floor on every chunk including mid-TX, using a
median — both of the things `transcriber.NoiseFloorTracker` documents as wrong.
Measured: floor `-37.0 dB` on noise → `+3.0 dB` after 20s of signal. One 20s
transmission produced a 0.1s fragment, a 2.6s fragment, then 17.4s of deafness,
with SNR reported ~0 dB for a signal 40 dB up. That bogus SNR silently disables
`sei_model.identify` (needs 15 dB) and `collect_sample` (needs 10 dB).
The 101 × 50 MB files on disk were literally this bug.
**Fix:** freeze the floor while `_in_tx`; use a low percentile.

### 5. Hailo inference runs on the eventlet hub [V]
`transcriber.py:6` imports patched (green) `threading`, so the inference thread is
a **greenthread** running blocking C calls with no yield. Up to ~2.5s of total
server freeze per transcript — no HTTP, no Socket.IO, no arbiter tick. The
codebase already noticed the symptom: `apt_scheduler.py:181` blames drift on
"eventlet greenthread starved by ... Hailo inference".
**Fix:** real OS thread + real queue + `emit_safe`.

### 6. Audio queues are green queues written by real OS threads [V]
`input_source.py:52-53` built from the patched `queue`; producers in `tuner.py`
are real threads. Reproduced `greenlet.error: Cannot switch to a different
thread`, and lost wakeups: consumer arrival times `[0.0, TIMEOUT@5.0, 5.0, 5.0…]`.
So `/audio-stream` delivers **5-second bursts** and the transcriber adds ~1s
latency. Full-queue `put` raises after 0.5s into `except Exception: pass` —
silent audio loss. **Fix:** `original("queue").Queue`.

### 7. Half of all satellite passes are lost to dongle contention [V]
Nothing preempts an already-running IQ-collect slot (dwell up to 240s).
Journal: **11 of 22** APT passes died with `APT WAV not created / empty (device
busy)` ~23ms after "recording started"; 4 completed. A 68°-elevation NOAA-15 pass
was lost to a 345 MHz corpus dwell. **Fix:** `preempt()` on the collector, called
from both pass handlers; broaden `should_yield`.

## HIGH — fixed except where noted

Remaining: the `/audio-stream` fan-out (one shared queue, so two tabs still
split the chunks between them) and the multi-MB `classify_iq` path.


- **`IQSegmenter.feed()` = 237% of one core** [V] at 2.4 MS/s — a list realloc +
  `np.median` 2,344×/sec. `iq_collector.py:98` sends rtl_sdr stderr to DEVNULL so
  the resulting sample loss is invisible. Fix: `deque(maxlen=)`, periodic median.
- **SEI emits from a real thread** [C] — `app.py:581` passes `_late_emit`; reached
  from the IQ collector's real thread → green lock + green socket in
  `ipc_server.broadcast`. One-word fix: `emit_safe`.
- **ADS-B scan scheduler cannot succeed and bypasses the arbiter** [V] — gates on
  `category == "aviation"`, which after the preset cleanup contains only `adsb`
  and `acars` modes. On ACARS it fights `acarsdec` for the dongle: 20+ minutes of
  `dump1090 exited immediately (code 1)` retry cycles in the log. It also resumes
  via `input_source.tune()` directly, defeating `sdr_arbiter`.
- **Waterfall redraw is 85k `fillRect`/sec** [V] — `classifier.js:239-272`
  repaints all 100 rows × 256 bins at 3.3 Hz, with a string allocation per cell,
  and runs even when hidden. Fix: `drawImage` scroll + paint one row; bail on
  `document.hidden`.
- **`/audio-stream` has no fan-out** [C] — all clients share one queue; two tabs
  each get ~half the chunks. The 2s auto-retry makes this easy to hit.
- **`AprsPanel` double-constructs on every reconnect** [C] — `ravensdr.js:84`
  missing `&& !aprsPanel`; the only unguarded panel of eleven. Leaks an instance
  and an extra full table rebuild per reconnect.
- **Preemption is 11 hand-maintained tuples** [C] — APRS is missing from the APT,
  WEFAX, pager and `/api/stop` paths; WEFAX preempts almost nothing. Adding a
  decoder requires editing eleven places. Fix: one `DEDICATED_DECODERS` registry.
- **`_exit_wefax` blind-sleeps** [C] `app.py:528` — pins the radio for
  `duration+30s` even if capture died in 4s. `_exit_apt` was fixed; this wasn't.
- **`_on_apt_pass_start` kills decoders before checking automation** [C]
  `app.py:398` — with automation off it preempts, logs "not preempting", and
  returns, leaving the dongle unclaimed.
- **IQ-collect never hands the radio back** [C] `app.py:1237` — reads
  `current_preset` *after* `input_source.stop()` set it to `None`.
- **372 MB of allocation churn per transcript** [V] `transcriber.py:896-908` —
  6.64 MB zeroed ×4 tensors per decode step, ×28 steps, of which one 207 KB row
  is used.
- **`classify_iq` on multi-MB segments** [V] — 1.96s and ~100 MB for a 2.6s
  segment, on the collector's reader thread, then decimated to 224 rows anyway.

## MEDIUM (selected)

- `_forward_to_sei` has never worked [C] — omits `snr_db`, so `identify()` always
  returns on the 15 dB gate. SEI is also invoked twice per segment.
- Transcriber fallback can loop forever with `_whisper_model = None` [C]
  `transcriber.py:963` — every chunk filed as `filtered [empty]`.
- APT records a fixed 900s but `_exit_apt` waits `duration+30` [C] — for an 853s
  pass the resume tunes while the APT `rtl_fm` is still recording.

  lexicographically, so fresh NOAA-15 passes never surface. Same for `NOJ`/`NMC`.
- `ObservationLog` mutated from real threads with no lock [C] — plus an inline
  SD-card write on the decoder thread every 30s.
- Five POST routes 500 on well-formed-but-wrong JSON [V] — `get_json(force=True)`
  with no dict check, plus unguarded `int()` coercion.
- `PagerPanel` has the ACARS desync that was just fixed in `acars.js` [C]; six
  more panels never reconcile after reconnect.
- APRS weather parsed from every payload [V] — a digipeater comment `...t072`
  becomes a temperature reading.
- ACARS `record_key` collides [C] — messages with no tail/flight collapse onto a
  shared `msg-<msgno>` key and overwrite each other.
- FLEX regex eats the first word when no type token is present [V].
- `_store` merges stale fields into records that never existed [C] — a sensor's
  hour-old temperature persists with a fresh `seen` timestamp.
- `on_connect` broadcasts to all clients [C] instead of the joining one, and fans
  out over IPC each time.
- Unbounded transcript feed [C] — ~2,900 entries/day, no cap.
- Celestrak outage → a 15s HTTP request every 15s forever [C].
- `_notified_passes` / `_recorded_passes` never pruned [C] (WEFAX prunes; APT doesn't).
- `set_last_preset` rewrites `config.json` on every tune [V] — 35 SD writes in 6h.
